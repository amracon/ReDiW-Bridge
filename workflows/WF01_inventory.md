# WF01 - Historic Bridge Inventory Creation

## Objective

To create a georeferenced inventory of historic bridges in Bath.

## Inputs

- Existing GIS dataset
- Historic Environment Records
- Current photographs

## Software

- QGIS 3.40

## Procedure

1. Import GIS layer.
2. Verify coordinates.
3. Assign unique Bridge_ID.
4. Add construction date.
5. Add current photographs.

## Outputs

- bridges.gpkg
- bridge_inventory.csv
